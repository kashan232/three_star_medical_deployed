Purchase Lifecycle (Inward)

graph LR PO[Purchase Order] -- "Approval" --> GRN[Goods Receipt Note] GRN -- "Inventory In" --> Batch[Batch & Expiry] Batch -- "Return to Vendor" --> PRN[Purchase Return] GRN -- "Accounts Payable" --> VL[Vendor Ledger]

1. Purchase Order (PO): Official procurement request to suppliers.

2. Goods Receipt Note (GRN): Documentation of physical arrival and stock digitization.

3. Purchase Return (PRN): Formal document for returning goods to suppliers.

Sales Lifecycle (Outward)

graph LR SO[Sale Order] -- "Verification" --> SRN[Sale Receipt Note] SRN -- "Physical Delivery" --> DN[Delivery Note] SRN -- "Account Receivable" --> CL[Customer Ledger] SRN -- "Customer Return" --> SR[Sale Return]

1. Sale Order (SO): Initial booking and customer commitment.

2. Sale Receipt Note (SRN): Primary billing document (Invoice) that triggers financials.

3. Delivery Note (DN): Official dispatch document for warehouse shipments.

4. Sale Return: Procedure for reversed shipments and credit notes.

Return Management (PRN & SRN Return)

GRN Return (PRN)

  • Removes stock from specific batch.
  • Decreases Vendor Balance.
  • Generates Debit Note.

SRN Return (Sale Return)

  • Updates stock back to warehouse.
  • Updates Customer Balance.
  • Generates Credit Note.

* Integrated approval system ensures all returns are audited by management.

Chart of Accounts (COA)

The financial foundation of the system.

Hierarchical Tree Structure:

  • Level 1: Assets, Liabilities, Equity, Revenue, Expense.
  • Level 2: Control Accounts (e.g., Accounts Receivable).
  • Level 3: Sub-Accounts (Customers, Vendors, Banks).

* Every transaction creates a balanced Journal Entry (Debit = Credit).
